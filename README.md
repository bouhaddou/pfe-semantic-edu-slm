# AI-Powered Semantic Modeling of Educational Content
# Using Small Language Models

PFE Master — Université Ibn Zohr
Faculté Polydisciplinaire de Ouarzazate — 2026

## Description
Ce projet évalue si un SLM de 1.5B paramètres
fine-tuné par LoRA peut extraire des concepts
éducatifs aussi bien que des modèles 7-14x plus
grands en zero-shot.

## Structure
- data/        — corpus eduDS + données traitées
- notebooks/   — expériences Colab numérotées
- src/         — code Python réutilisable
- results/     — métriques et résultats
- report/      — mémoire LaTeX complet
- models/      — adaptateurs LoRA fine-tunés
